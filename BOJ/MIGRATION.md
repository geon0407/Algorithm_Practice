# BOJ 아카이브 이전 기록

115개 C++ 소스의 바이트와 SHA-256을 원본 ZIP과 대조했습니다. 재채점 결과를 의미하지 않습니다.

- 구조: `BOJ/티어/번호.제목/제목.cpp`
- 세부 난이도(예: Silver IV)는 각 문제 README에 표시합니다.
- 제목·난이도는 solved.ac 페이지 및 검색 색인에서 확인했습니다. 실시간 API 조회 결과는 아니며 이후 티어가 변경될 수 있습니다.
- 문제별 출처 URL, 원본 경로, 대상 경로와 SHA-256은 `MIGRATION.json`에 있습니다.
- 경로의 공백은 일반 공백으로 정규화하고 파일명 금지 문자는 전각 문자로 치환했습니다.
- 기존 저장소 README는 `ARCHIVE.md`로 보존했습니다.
- 시간·메모리·제출일·문제 본문은 새로 만들어 넣지 않았습니다.
